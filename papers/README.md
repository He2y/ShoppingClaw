# papers/ 目录约定

本目录存放基于 `phone_agent/docs/` 三份架构文档撰写的学术论文稿件。

## 文件清单

| 文件 | 内容 | 目标 |
|---|---|---|
| `amsg-paper-cn.md` | AMSG 主动空间图谱方法论文（中文初稿） | 顶会算法/方法类小论文，后续译英投稿 |
| `thesis-cn.md` | 移动端购物智能体系统（中文初稿） | 硕士毕业论文 |
| `amsg-experiment-plan.md` | AMSG 实验执行计划（**非稿件**，过程文档） | 驱动第 4 章实验落地：harness/修复/任务集/执行阶段 |
| `amsg-sim-env-analysis.md` | 模拟环境方案分析（**非稿件**，过程文档） | 三篇论文精读 + 对抗核验：5 个 sim 方案排序 + 补数据优先 |

## 写作约定

- 事实来源以 `phone_agent/docs/AMSG_DESIGN.md` 与 `ARCHITECTURE_CN.md`（2026-06-12 审计版）为准，不得引入文档未核验的性能数字。
- 实验章节当前为**框架占位**（研究问题 / 基线 / 指标 / 消融矩阵已定，数据待真机实验补充），占位处统一用 `【实验数据待补充】` 标记。
- 延迟、调用次数等运行特征数字（如 ~0.5s / ~5s / 1+步数/5）来自架构文档的实测估算，正式投稿前需替换为实验测量值。
- 修改稿件请直接编辑对应文件并 commit，不另存版本副本（git 即版本历史）。
- 参考文献暂以方括号占位（如 [PG-Agent, MM'25]），定稿时统一替换为正式编号引用。

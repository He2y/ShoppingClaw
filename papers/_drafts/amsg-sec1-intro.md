# AMSG：面向真实移动应用的主动空间图谱——以自进化页面-动作图谱弥合小型 GUI 模型的长任务导航缺口

**AMSG: Active Mobile Spatial Graph — A Self-Evolving Page-Action Graph for Long-Horizon Navigation of Small GUI Models in Real-World Mobile Apps**

## 摘要

可端侧部署的小型 GUI 模型具备精确的指令落地（grounding）能力，但缺乏长程规划能力：在弹窗、广告与 A/B 测试构成的高干扰真实移动应用环境中，长任务执行极易迷失。将页面-动作关系组织为图谱以提供导航先验是一条有效路线，但现有图谱方法存在三个根本缺陷：图谱静态冻结，应用迭代使边失效而系统不自知；边仅为布尔存在性，同一操作的多种结果被无差别存入；图谱与 VLM 的控制边界一刀切，或始终检索增强而不节省调用，或直接接管导航而无回退。为此，本文提出主动移动空间图谱（Active Mobile Spatial Graph, AMSG），一种"活的"页面-动作图谱导航方法：（1）自动持久化的活图谱——在线学习持续吸收成功任务的执行观测，统计驱动的自修复降级应对 UI 漂移；（2）边级成功率追踪与 hypothesis→candidate→promoted→demoted 四阶段生命周期——以统计可靠性替代布尔存在性，仅统计达标的边对智能体可见；（3）锚定性分类逐边划定图谱与 VLM 的控制边界——锚定且可靠的边走跳过 VLM 的快速路径，非锚定的边永远保留 VLM 决策，并以 t+1 延迟后条件验证（以"实际到达哪"而非"以为会到哪"为事实来源）作为全部统计的真实性根基。AMSG 配套可复制的陌生 App 五阶段建图管线与跨应用泛化机制，已在淘宝与京东（含秒送外卖链路）两个真实应用上完成端到端验证。实验结果方面，【实验数据待补充】。

**关键词**：GUI 智能体；移动应用导航；页面-动作图谱；在线学习；边生命周期；视觉语言模型

## 1 引言

视觉语言模型（Vision-Language Model, VLM）驱动的 GUI 智能体正在使"以自然语言指挥手机完成任务"成为现实。其中一条对实际部署尤为重要的技术路线，是使用可端侧部署的小型 GUI 模型（如 autoglm-phone-9b 这类 9B 量级模型 [AutoGLM, arXiv 2024]）作为执行器：此类模型经 GUI 专用后训练，能够将一条具体指令精确地落地（ground）为屏幕坐标，且推理成本与隐私属性均适合在设备本地运行。然而，真实移动应用是一个高干扰环境——弹窗、广告、A/B 测试、登录墙与版本迭代使页面形态持续变动，而长任务（如"按预算与规格约束完成一次网购"）要求跨越十余个页面的连贯导航。在这样的环境中，小型 GUI 模型呈现出一种鲜明的能力裂隙：grounding 精确，规划缺位。我们在真机建图实验中观察到（此处为真机观察而非正式实验结论）：小模型能把"点击右上角的筛选按钮"准确 ground 到坐标，却不知道达成"覆盖搜索结果页到筛选面板的转移"这一目标需要点哪个按钮，于是永远在熟悉的主链路上打转。换言之，小模型缺少的不是"手"，而是关于应用状态空间的"地图"。

为小模型补上这张地图，图谱化是一条直觉正确的路线。PG-Agent 指出：页面天然构成图，智能体的线性执行轨迹本质上是图上的路径采样，从多条轨迹重建页面图远优于孤立地复用单条轨迹 [PG-Agent, ACM MM 2025]。这一洞察我们完全认同，AMSG 也以其为起点。然而，我们认为以 PG-Agent 为代表的现有图谱方法——包括将 UI 转移图向量化检索的 KG-RAG [KG-RAG, EMNLP 2025]、以交互图直接接管导航的 WebNavigator [WebNavigator, arXiv 2026]，以及基于轨迹记录-重放的 MobiAgent [MobiAgent, arXiv 2025]——共享三个根本缺陷，使图谱在真实移动环境中难以长期可用。

**缺陷一：图谱静态冻结。** 现有方法均从离线收集的数据批量构建图谱，部署后只读不写。但移动应用平均每 2-4 周更新一次 [文献待补]，按钮移位、流程变更会持续使边失效；由于系统不追踪边的实际执行结果，它既不知道哪些边已经腐烂，也无法把新页面写回图谱，只能依赖周期性的全量重建。

**缺陷二：边的可靠性不区分。** 现有图谱的边仅记录"页面 A 经动作 X 可达页面 B"这一布尔事实。而真实应用中同一动作可能有多种结果——考虑一个假想例：点击"立即购买"可能进入规格选择页、可能被登录页拦截、也可能弹出促销弹窗。布尔边将这些结果全部当作有效转移存入，规划器可能选中一条仅在特定条件下成立的路径而毫无察觉。

**缺陷三：图谱与 VLM 的控制边界一刀切。** 现有方法在"图谱多大程度上接管导航"上走向两个极端：PG-Agent 与 KG-RAG 把图谱仅作为检索增强材料，VLM 仍逐步推理——图谱改善了提示内容却不节省任何模型调用；WebNavigator 则让图谱直接 Teleport 式接管导航——一旦边因应用更新失效便无回退机制。两个极端都忽视了一个事实：并非所有转移都同质，有的可以放心交给图谱，有的必须留给 VLM。

针对三个缺陷，本文提出三条一一对应的洞察。其一，图谱必须是"活的"：智能体的每一步执行本身就是免费的验证数据流，关键在于以"实际到达了哪个页面"而非"以为会到达哪个页面"作为事实来源——由此引出 t+1 延迟后条件验证，即在下一步观测时回头核验上一步转移是否如预期发生。其二，边的价值在于统计可靠性而非存在性——由此引出边级成功率追踪与 hypothesis→candidate→promoted→demoted 四阶段生命周期：边须经反复验证方可提升为智能体可见，可靠性下降则自动降级，统计偏移本身即是 UI 变更信号，自修复无需人工干预。其三，页面转移天然分为两类：位置固定、结果确定的机械转移（锚定，如首页到搜索框），与依赖当前屏幕内容的决策转移（非锚定，如在搜索结果中选哪个商品）——由此引出逐边划定控制强度：锚定且统计可靠的边走跳过 VLM 的快速路径以节省调用，非锚定的边永远保留 VLM 推理而图谱仅提供方向提示。三条洞察共同把图谱从"静态导航知识库"升格为"自进化的可执行动作库"。

我们将上述设计实现为主动移动空间图谱（Active Mobile Spatial Graph, AMSG），并构建了配套的陌生 App 冷启动建图管线与多 App 组织机制。本文的主要贡献如下：

1. **自动持久化的活图谱。** 提出以在线学习为持续供给、以质量门控制写入的图谱演化机制：成功任务的执行观测经语义去重与审核后自动并入图谱，可靠性下降的边经统计降级自动收缩，使图谱在应用持续迭代下保持可用，并具备无人工干预的 UI 漂移自修复能力。

2. **边级成功率追踪与四阶段生命周期。** 以 hypothesis→candidate→promoted→demoted 状态机替代布尔存在性边：只有统计上可靠（验证次数与优势比达标且非高风险）的边才对智能体可见，从根本上避免偶发转移污染规划。

3. **锚定性分类的图谱/VLM 边界与 t+1 延迟后条件验证。** 每条边独立决定控制强度——锚定边走快速路径节省 VLM 调用，非锚定边保留 VLM 决策——避免"永远 RAG"与"永远 Teleport"两个极端；并以延迟后条件验证作为全部成功率统计的事实来源，保障生命周期系统的统计真实性。

4. **可复制的陌生 App 建图管线与跨 App 泛化机制。** 提出"引导→焦点探索→staging→人工审核→hypothesis 入图"五阶段管线，其中探索阶段采用强 VLM 规划与小 GUI 模型执行分离的架构以补足小模型的规划缺位；配合多 App 单库逻辑分区与同域结构先验，使同一领域的新 App 可按相同流程从零完成建图并获得冷启动方向感。

系统已在淘宝（核心购物流程）与京东（核心流程及秒送外卖链路）两个真实应用上完成端到端验证。本文余下部分组织如下：第 2 章回顾相关工作并定位 AMSG 与现有图谱方法的差异；第 3 章详述 AMSG 的图谱表示、运行时集成、在线学习与生命周期机制，以及陌生 App 建图管线；第 4 章给出实验设计与结果；第 5 章总结全文并讨论局限。
